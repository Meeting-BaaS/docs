Speaking Bots requires a few API keys and configuration values to function. Here's a quick setup guide:

1. Copy the example environment file:

```bash
cp env.example .env
```

{" "}

<Callout type="warn">
  Never commit your `.env` file to version control. It contains sensitive API
  keys that should be kept private.
</Callout>

2. Add your credentials to `.env`: you need 3 keys for core functionality (an LLM provider, speech-to-text and text-to-speech). Additional keys can be added later for optional features.

<Callout>
  Your MeetingBaas API key is not an environment variable of the server. Each `POST /bots` request carries it in the `x-meeting-baas-api-key` header, and the bot is created on that account.
</Callout>

## Core Bot Functionality (Required)

<Steps>
<Step>
### LLM Configuration

Powers in-meeting AI interactions. Pick a provider and set its key; a request can override the provider and model per bot with `llm_provider` and `llm_model`.

```txt
# openai (default), anthropic or zai
LLM_PROVIDER=openai

OPENAI_API_KEY=your_openai_api_key_here
OPENAI_MODEL=gpt-5.5
# responses (default, newest models) or chat
OPENAI_API_SURFACE=responses

# ANTHROPIC_API_KEY=your_anthropic_api_key_here
# ANTHROPIC_MODEL=claude-opus-4-8

# ZAI_API_KEY=your_zai_api_key_here
# ZAI_MODEL=glm-5.2
# ZAI_BASE_URL=https://api.z.ai/api/paas/v4/
```

`LLM_MODEL` is an optional global fallback model; the provider-specific variables take precedence.

<Callout>
  The OpenAI key is also used by the persona creation CLI, which matches a new persona to a Cartesia voice.
</Callout>
</Step>

<Step>
### Speech-to-Text Configuration

Choose one of the following options:

#### Option 1: Deepgram

```txt
DEEPGRAM_API_KEY=your_deepgram_api_key_here
```

#### Option 2: Gladia

```txt
GLADIA_API_KEY=your_gladia_api_key_here
```

</Step>

<Step>
### Text-to-Speech Configuration

Required for voice synthesis and persona voices:

```txt
CARTESIA_API_KEY=your_cartesia_api_key_here
CARTESIA_VOICE_ID="79a125e8-cd45-4c13-8a67-188112f4dd22"
# Default speaking speed when a request sets no speech_speed (0.6 to 1.5)
CARTESIA_TTS_SPEED=1.2
```

</Step>
</Steps>

## Server Configuration

```txt
# Port the API listens on
PORT=7014

# Public https URL of this server. The MeetingBaas bot connects back to
# wss://<this host>/ws/<client_id> for audio, so set it everywhere except a
# local ngrok run (where it is detected automatically).
BASE_URL=https://your-server-domain.com

# MeetingBaas API the bots are created on (pre-prod: https://api.pre-prod-meetingbaas.com)
MEETING_BAAS_API_URL=https://api.meetingbaas.com

# Comma-separated CORS origins; unset allows every origin
CORS_ALLOW_ORIGINS=

# When set, MeetingBaas callbacks to /webhook must carry it in x-mb-secret
WEBHOOK_SECRET=

# Writable directory for transcripts, floor files and call summaries
# (defaults to the repository root)
SPEAKING_BOT_STATE_DIR=/data
```

## Optional Features

### External Context and MCP Tools

```txt
# Cap on each prompt_data_sources URL fetch
PROMPT_DATA_SOURCE_MAX_BYTES=1000000
# Allow prompt_data_sources URLs on localhost / private networks (trusted networks only)
PROMPT_DATA_ALLOW_PRIVATE_URLS=false

# Allow remote MCP servers on localhost / private networks (trusted networks only),
# or list exact private URLs that are allowed
MCP_ALLOW_PRIVATE_URLS=false
MCP_ALLOWED_PRIVATE_URLS=

# Local mcpproxy groups behind the mcp_profile presets
MCP_PROXY_ALL_URL=http://127.0.0.1:8109/mcp
MCP_PROXY_PERSONAL_URL=http://127.0.0.1:8110/mcp
MCP_PROXY_PROFESSIONAL_URL=http://127.0.0.1:8111/mcp
```

MCP server credentials are passed per request in `mcp.servers[].headers`; no global MCP secret is needed.

### Multiple Bots Support

<Steps>
<Step>
Required for running multiple bots in local development:
```txt
NGROK_AUTHTOKEN=your_ngrok_auth_token_here
```

<Callout>
  Follow our [Ngrok Setup Guide](/docs/speaking-bots/getting-started/ngrok-setup) to get your auth token.
</Callout>
</Step>
</Steps>

### Persona Creation

Required only for AI image generation and hosting when creating personas (`POST /personas/generate-image` and the persona CLI):

```txt
REPLICATE_KEY=your_replicate_key_here
STABILITY_AI_API_KEY=your_stability_ai_key_here
UTFS_KEY=your_utfs_key_here
APP_ID=your_app_id_here
```
